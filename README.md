Kredete take-home minimal implementation

Run with:

Option A (recommended): create a venv, install deps, and run with bash

```bash
python3 -m pip install -r requirements.txt
bash run.sh
```

Option B: make the script executable and run it directly

```bash
chmod +x run.sh
./run.sh
```

Then open http://127.0.0.1:8000/static/index.html to try the UI.
